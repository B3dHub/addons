## Introduction

Megascans Bridge is a Blender add-on that imports Quixel Megascans assets downloaded via [Quixel Bridge](https://d2shgxa8i058x8.cloudfront.net/bridge/win/Bridge.exe) directly from the Blender interface. The downloaded assets will be sorted by type, category and subcategory. The add-on does not support online downloading — it only imports Quixel Megascans assets that have already been downloaded to your local library.

> Disclaimer: Users who have `claimed` or `purchased` Megascans assets through `Quixel Bridge` and downloaded them locally can use this add-on.

> Note: The add-on does not download assets from the internet. It only imports Quixel Megascans assets that have already been downloaded to your local library.

## Features

- Grid View
- Asset Search
- Asset Details
- Pagination
- Import Assets
- Import Plants
- Import Surfaces
- Import LODs
- Create Lod Group
- Apply Imported Materials
- Import Other Asset Types from Shader Editor
- Import Brushes from Texture Paint Mode

## Workflow

1. Download [Quixel Bridge](https://d2shgxa8i058x8.cloudfront.net/bridge/win/Bridge.exe) and download the Megascans assets through it.
2. Once you download the Megascans assets, they will be saved in the default path `"/Documents/Megascans Library/Downloaded/"`.
3. Add the path in the add-on preferences under the `Library` tab.
4. After adding the path, the assets will appear in the `Sidebar(n-panel)` under the `M-Bridge` tab.
5. Now you can import the assets directly from the Blender interface.
