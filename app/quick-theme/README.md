## Introduction

Are you tired of the default Blender theme?

Quick Theme is a Blender addon that consolidates all the theme settings into one panel. You can craft a theme with a single color slider, theme the Interface, Viewport, Outliner, and Annotations, or change the theme automatically with Auto Theme. This addon is perfect for anyone who wants to improve their workflow and productivity in Blender.

## Features

- Auto Theme
- Interface Theme
- Viewport Theme
- Outliner Theme
- Annotations Color

## Auto Theme

Change the theme automatically based on the system theme. The theme will change on restart or when a new file is loaded.

![Toggling Auto Theme based on system theme](https://b3dhub.github.io/addons/images/quick-theme/auto_theme_toggle.gif)

![Theme changing automatically with Auto Theme](https://b3dhub.github.io/addons/images/quick-theme/auto_theme.gif)

## Interface Theme

Craft a theme with a single color slider. You can also adjust the roundness of the interface.

![Crafting interface theme with single color slider](https://b3dhub.github.io/addons/images/quick-theme/interface_theme.gif)

## Viewport Theme

Theme the viewport. The viewport theme is linked to the interface theme by default. You can unlink them with the link icon.

![Theming the viewport with color slider](https://b3dhub.github.io/addons/images/quick-theme/viewport_theme.gif)

## Outliner Theme

Theme the outliner. The outliner theme is linked to the interface theme by default. You can unlink them with the link icon.

![Theming the outliner with color slider](https://b3dhub.github.io/addons/images/quick-theme/outliner_theme.gif)
