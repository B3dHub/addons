## Introduction

Camera Preview is a Blender addon that lets you preview your camera view directly in the 3D viewport, similar to Unreal Engine. It supports multiple cameras with adjustable position, offset, and size, plus camera properties in the preview header. This addon is perfect for anyone who wants to improve their workflow and productivity in Blender.

## Features

- Multiple Camera Preview
- Preview Position
- Preview Offset
- Preview Size
- Camera Properties in Preview Header
- Object Hide/Unhide

## Limitations

- Rendered mode in Cycles is not supported.
- Background images in camera are not supported.
