## Introduction

Fab Bridge is a Blender add-on that imports Quixel Megascans [Fab](https://www.fab.com/sellers/Quixel%20Megascans) assets downloaded through the Epic Games Launcher directly from the Blender interface. The downloaded assets will be sorted by type, category and subcategory. The add-on does not support online downloading — it only imports Quixel Megascans Fab assets that have already been downloaded to your local library.

> Disclaimer: Users who have `claimed` or `purchased` Quixel Megascans Fab assets through Epic Games Launcher and downloaded them locally can use this add-on.

> Note: The add-on does not download assets from the internet. It only imports Quixel Megascans Fab assets that have already been downloaded to your local library.

## Features

- Grid View
- Asset Search
- Asset Details
- Pagination
- Import Assets
- Import Plants
- Import Materials
- Import Decals
- Import LODs
- Create Lod Group
- Apply Imported Materials
- Import Other Asset Types from Shader Editor
- Import Brushes from Texture Paint Mode

## Workflow

1. Download the [Epic Games Launcher](https://store.epicgames.com/en-US/download) and download the Fab assets through it.
2. Once you download the Fab assets, they will be saved in the default path `"C:\ProgramData\Epic\EpicGamesLauncher\VaultCache\FabLibrary"`.
3. Add the path in the add-on preferences under the `Library` tab.
4. After adding the path, the assets will appear in the `Sidebar(n-panel)` under the `Fab Bridge` tab.
5. Now you can import the assets directly from the Blender interface.
